# Exercícios de SQL — Banco de dados Chinook

Projeto de prática de consultas SQL desenvolvido durante a formação em Quality Assurance (QA) na EBAC. O arquivo `Atividade SQL.sql` reúne consultas para explorar dados de artistas, álbuns, músicas, gêneros e clientes.

## Objetivos

Praticar consultas relacionais e validação de dados por meio de:

- Ordenação de artistas por nome;
- Filtro de músicas com duração superior a cinco minutos;
- Consulta de músicas por gênero;
- Junção entre álbuns e artistas;
- Busca de músicas de um álbum específico;
- Filtro de clientes por país;
- Agrupamento e contagem de músicas por gênero;
- Busca textual por músicas que contenham “Love” no título.

## Tecnologias

- SQL
- Banco de dados compatível com o esquema Chinook (tabelas como `Artist`, `Album`, `Track`, `Genre` e `Customer`)

## Pré-requisitos

- Um SGBD e uma cópia do banco de dados Chinook carregada.
- Um cliente SQL compatível com o SGBD escolhido.

> O arquivo contém consultas escritas para um esquema do tipo Chinook. A sintaxe pode precisar de ajustes dependendo do SGBD utilizado.

## Como executar

1. Prepare e carregue o banco de dados Chinook no seu SGBD.
2. Abra o arquivo `Atividade SQL.sql` no cliente SQL.
3. Execute as consultas individualmente e confira os resultados.
4. Compare os resultados com os comentários que descrevem cada exercício.

## Arquivo principal

- `Atividade SQL.sql` — contém as oito consultas propostas e suas instruções.

## Observações

Este repositório é um exercício educacional de consultas SQL. Ele não contém, por si só, o arquivo de banco de dados; a base Chinook deve ser preparada separadamente.
